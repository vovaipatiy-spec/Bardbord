# E-cammerce
This is a demo app, written in Java Spring Boot.

Development in progress.

## API documentation

- Swagger UI: http://localhost:8080/swagger-ui.html
- OpenAPI YAML: http://localhost:8080/openapi.yaml
- Generated OpenAPI JSON: http://localhost:8080/v3/api-docs

Для защищённых запросов получите токен через `POST /api/auth/login`
и нажмите **Authorize** в Swagger UI, указав его без префикса `Bearer `.
